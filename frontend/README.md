# NazarovGroup frontend

Публичный Next.js App Router frontend. Полные инструкции по архитектуре, environment и запуску находятся в корневом [`README.md`](../README.md).

```bash
npm ci
npm run dev
```

Перед передачей изменений запускайте `npm run lint`, `npm run typecheck`, `npm run format:check` и `npm run build`.
